
# 🎯 C++ Number Guessing Game

A simple interactive number guessing game built with C++.

## How to Play

- Guess a secret number between 1 and 100.
- Get hints when your guess is too high or too low.
- Try to guess the number in as few attempts as possible.
- Play again as many times as you want!

## ✨ Features

- Randomly generated secret numbers
- Helpful high and low hints
- Attempt counter
- Performance messages based on your score
- Option to replay
- Input validation
